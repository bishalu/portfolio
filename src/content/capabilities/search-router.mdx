Most catalog searches don't need an embedding model, and the ones that do are ruined by
exact matching. The router classifies each query and dispatches it: exact SQL for
structured filters, hybrid retrieval when the query is partly literal, semantic vector
search when it's a description rather than a name. Latency spans two orders of magnitude
across those paths, which is the point — the cheap path stays cheap.
